# 每層背景場景放這裡

檔名 `floor1.webp` / `floor2.webp` / `floor3.webp`（對應 3 層）。放入後自動套用，
遊戲會疊一層暗罩確保前景可讀；缺圖則維持預設漸層。建議橫向 16:9（約 1280×720）webp。

| 檔名 | 層 | Recraft prompt 建議 |
|---|---|---|
| `floor1.webp` | L1 | inside a stone fantasy tower, mossy lower floor, soft torchlight, game background, 16:9 |
| `floor2.webp` | L2 | fantasy tower mid floor, stairs and banners, dramatic torchlight, game background, 16:9 |
| `floor3.webp` | L3 (Boss) | top of a fantasy tower, grand boss chamber, glowing runes, ominous, game background, 16:9 |

> 也可只放一張當共用底圖：複製成 floor1/2/3 即可。
